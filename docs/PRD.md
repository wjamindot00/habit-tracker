# 습관 트래커 — 미니앱 PRD

> 상태: 초안 v0.1 · 최종 수정: 2026-10-05

---

## 1. 한 줄 요약
매일 지키고 싶은 습관을 등록하고, 오늘 했는지 체크하고, 며칠 연속으로 지켰는지(스트릭) 확인하는 웹 앱.

## 2. 문제와 목표
| | 내용 |
|---|---|
| 문제 | 습관을 정해도 "어제 했나?", "몇 일째지?"를 기억하기 어렵고, 기록이 없으니 금방 포기한다. |
| 목표 | 체크 한 번으로 기록하고, 연속 기록을 눈으로 보며 동기를 유지한다. |
| 사용자 | 나 자신 (1인 사용, 로그인 없음) |

## 3. 개발 원칙
1. **기능 먼저, 꾸미기는 나중에.** M1~M3은 버튼과 목록만 있는 "못생긴 화면"이어도 된다. 대신 로직은 정확해야 한다.
2. **로직과 화면을 분리한다.** 핵심 로직(`src/core/`)은 화면 없이 테스트할 수 있는 순수 함수로 만든다. UI는 나중에 통째로 바꿔도 로직은 그대로.
3. **마일스톤 하나 = 브랜치 하나 = PR 하나.** 완료 기준(DoD)을 모두 체크해야 다음 마일스톤으로 간다.
   작업 브랜치는 `develop`에서 만들어 `develop`으로 머지하고, `main`은 배포용으로 `develop`에서만 머지한다.
4. **의존성 최소화.** 설치 없이 브라우저와 Node만으로 동작.

## 4. 기능 요구사항

### 4.1 핵심 기능 (MVP — 반드시)
| ID | 기능 | 설명 |
|---|---|---|
| F1 | 습관 추가 | 이름(필수, 1~30자)을 입력해 습관을 만든다. 같은 이름 중복 불가. |
| F2 | 습관 목록 | 등록한 습관을 생성 순으로 본다. |
| F3 | 습관 수정/삭제 | 이름 변경, 삭제(삭제 전 확인). |
| F4 | 오늘 체크 | 습관별로 오늘 완료/미완료를 토글한다. |
| F5 | 스트릭 | 오늘(또는 어제)까지 연속으로 완료한 일수를 보여준다. |
| F6 | 데이터 저장 | 새로고침·브라우저 재시작 후에도 데이터 유지 (localStorage). |

### 4.2 부가 기능 (MVP 이후)
| ID | 기능 | 설명 |
|---|---|---|
| F7 | 최근 7일 기록 | 습관별 최근 7일 체크 현황을 ●○로 표시. |
| F8 | 지난 날짜 체크 | 어제 깜빡한 기록을 지난 7일 이내로 소급 체크. |
| F9 | 통계 | 최장 스트릭, 이번 달 달성률. |
| F10 | 백업/복원 | JSON 파일로 내보내기·가져오기. |

### 4.3 하지 않는 것 (Out of Scope)
- 로그인, 서버, 여러 기기 동기화
- 알림/푸시
- 주 3회 같은 "요일별 목표" (모든 습관은 매일 목표로 단순화)

## 5. 데이터 모델

```js
// localStorage key: "habit-tracker:v1"
{
  version: 1,
  habits: [
    {
      id: "h_1696500000000",   // 생성 시각 기반 고유 ID
      name: "물 2L 마시기",
      createdAt: "2026-10-05", // YYYY-MM-DD (로컬 날짜)
      checks: ["2026-10-04", "2026-10-05"] // 완료한 날짜 목록, 오름차순, 중복 없음
    }
  ]
}
```

### 5.1 스트릭 계산 규칙 (F5)
- 날짜는 항상 **사용자 로컬 시간 기준 `YYYY-MM-DD` 문자열**로 다룬다 (시간대 버그 방지).
- 오늘 체크했으면: 오늘부터 거꾸로 연속된 날 수.
- 오늘 아직 안 했으면: 어제부터 거꾸로 연속된 날 수. (오늘 안 했다고 바로 0이 되지 않음)
- 어제도 안 했으면: 0.

| 체크된 날 (오늘 = 10/05) | 스트릭 |
|---|---|
| 10/03, 10/04, 10/05 | 3 |
| 10/03, 10/04 | 2 (오늘 아직 안 함) |
| 10/01, 10/02 | 0 |
| (없음) | 0 |

## 6. 기술 스택 (잠정)
| 항목 | 선택 | 이유 |
|---|---|---|
| 언어 | HTML / CSS / JavaScript (ES Modules) | 빌드 도구 없이 바로 실행, 학습 부담 최소 |
| 저장 | localStorage | 서버 불필요 |
| 테스트 | Node 내장 테스트 러너 (`node --test`) | 추가 설치 없음 |
| 배포 | GitHub Pages | 무료, 저장소만 있으면 됨 |

## 7. 폴더 구조

```
habit-tracker/
├── index.html          # 진입점
├── src/
│   ├── core/           # 순수 로직 (DOM 접근 금지)
│   │   ├── date.js     # 날짜 유틸 (오늘, n일 전, 포맷)
│   │   ├── habits.js   # 추가/수정/삭제/체크 토글
│   │   ├── streak.js   # 스트릭·통계 계산
│   │   └── storage.js  # localStorage 읽기/쓰기
│   ├── ui/             # 화면 렌더링 + 이벤트
│   └── main.js         # core와 ui 연결
├── tests/              # core 단위 테스트
└── docs/PRD.md
```
